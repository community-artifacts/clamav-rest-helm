# clamav-rest-helm — Helm chart repository

This branch is the published Helm chart repository, served via GitHub Pages at:

  https://community-artifacts.github.io/clamav-rest-helm/

```
helm repo add clamav-rest https://community-artifacts.github.io/clamav-rest-helm
helm repo update
helm install av clamav-rest/clamav-rest
```

Chart source, issues and docs: https://github.com/community-artifacts/clamav-rest-helm
